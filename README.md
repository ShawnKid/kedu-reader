# 苛读（kedu-reader for Windows）

**把电子书还给你的电脑。**

不注册、不上传、不打扰——一款只关心「下一页」的 Windows 本地阅读器。

![苛读书架界面](介绍.png)

---

## 为什么还需要苛读

你可能已经受够了这些：

| 常见阅读器 | 苛读的选择 |
|------------|------------|
| 先注册账号，再谈阅读 | **零账号**，装好就能用 |
| 书库和进度「贴心」云同步 | **全程本地**，断网照读 |
| 启动像开了个浏览器 | **轻量桌面应用**，为阅读而生 |
| 功能堆到看不懂设置 | **只留有用的**：翻页、笔记、书架、统计 |
| 你读什么，平台比你更清楚 | **阅读行为不出本机** |

苛读不是又一个「内容平台」。  
它只做一件事：**让你安静地读完手边这本书。**

---

## 你会立刻喜欢上的 5 件事

### 1. 书是你的，数据也是你的  
拖进来的文件、划线、笔记、阅读时长——全部落在你自己的硬盘上。没有云，没有推送，没有「根据您的阅读习惯推荐…」。

### 2. 打开就进入阅读  
不用装服务端，不用配一堆环境。双击启动，书架就在眼前；关窗会尽量存好进度，下次接着读。

### 3. 翻页像在翻纸书  
分页支持**自然卷页**，也支持干净的标准翻页；滚动模式还有卷轴卷绕效果。宽屏自动双页，栏宽跟着窗口走——长文和漫画都不局促。

### 4. 把版式调到「你的眼睛说了算」  
字号、行距、页边距秒调；日间 / 夜间 / 护眼 / 护眼绿四套主题；可换系统字体，**单本书**也能单独覆盖。也支持「跟随图书设定」，尊重原书排版。

### 5. 书架够用，笔记够快  
拖拽导入、自动封面、分类与搜索；书签、划线、想法笔记；阅读统计帮你看见自己真的在读。没有花哨社交，没有无用入口。

## 格式覆盖

| 你能打开的 | 说明 |
|------------|------|
| **EPUB** | 目录、图片、原书 CSS |
| **MOBI / AZW3** | Kindle 常见本地书 |
| **TXT / LOG** | 编码自动识别，智能分章 |
| **Markdown** | 按标题分章，当笔记书读 |
| **FB2** | 含内嵌插图 |
| **CBZ** | 漫画按页浏览 |
| **PDF** | 常规阅读 |

> 检测到 **DRM 加密**内容会直接拒绝打开——不做破解，也不帮你绕过版权。

---

## 适合谁

- 书库里有本地 EPUB / MOBI / TXT，讨厌先登录再阅读的人  
- 在意隐私：不希望书名和进度进入任何云端的人  
- 想要「纸书感」卷页，又不想被臃肿客户端拖慢的人  
- 需要划线、笔记、进度和时长统计，但不需要阅读社交的人  

**不适合**：需要购买正版书城、多人云端书架、或 DRM 商店内容的用户。

## 快速开始（从源码构建）

**你需要：** Windows 10/11 · [Node.js](https://nodejs.org) 18+ · [Rust](https://rustup.rs) · Visual Studio C++ 生成工具 · WebView2（多数系统已预装）

```powershell
git clone https://github.com/ShawnKid/-kedu-reader-for-Windows-.git
cd -kedu-reader-for-Windows-

npm ci
npm run tauri dev      # 开发预览
npm run tauri build    # 打出安装包 / 可执行文件
```

产物默认在：`src-tauri/target/release/苛读.exe`

仅检查前端类型：`npm run typecheck`

## 给开发者

| 项 | 情况 |
|----|------|
| 形态 | Windows 桌面应用（非纯网页） |
| 前端 | 原生 TypeScript + Vite（无 React/Vue） |
| 后端 | 同仓库 Rust（`src-tauri`），Tauri 2 IPC |
| 存储 | 本地 JSON，可备份、可手工迁移 |
| 许可证 | [MIT](LICENSE) |

### 目录一览

```text
src/           前端（书架、阅读器、翻页、PDF…）
src-tauri/     Rust 解析与持久化
public/        静态资源
scripts/       构建辅助
介绍.png       README 首屏截图
```

### 贡献前请读

1. 不要悄悄改默认功能语义或 UI 视觉；大改请先开 Issue。  
2. 新后端能力请走 `src/ipc.ts`，保持与 `model.rs` 的 camelCase 契约。  
3. 提交前：`npm run typecheck`。  
4. 不要提交：真实书库、用户数据目录、`node_modules/`、`src-tauri/target/`、密钥。

隐私立场：无账号、无同步、无 API Key；书籍与阅读数据默认仅存本机。
